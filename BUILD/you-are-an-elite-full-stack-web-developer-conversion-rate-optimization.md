# You are an elite full-stack web developer, conversion-rate optimization specialist, and technical

You are an elite full-stack web developer, conversion-rate optimization specialist, and technical SEO expert with deep expertise in 2026 search (SEO + AEO + GEO). Your task is to build a complete, production-ready marketing website for Conextsol[](https://conextsol.co.za).

### Business Context
- Brand: Conextsol
- Domain: https://conextsol.co.za (South Africa)
- Owner: Professional web developer, designer, and software developer
- Core services: Custom website design & development, UI/UX design, custom software/web application development, e-commerce solutions, website maintenance & optimization, and related digital services
- Goal: Maximum qualified leads and clients through organic search only (no paid ads). Target 300× ROI on time invested via high-intent traffic that converts into enquiries, calls, WhatsApp messages, and booked discovery calls.
- Target audience: South African SMEs, startups, professional service firms, and growing businesses that need modern, high-performing websites and software. Primary locations: Johannesburg, Cape Town, Durban, Pretoria, and nationwide remote clients.
- Unique positioning: Results-driven, conversion-focused design + clean modern development + local understanding of South African business needs + transparent process and measurable outcomes.

### Primary Success Metrics the Site Must Optimize For
- High organic visibility for relevant commercial and local search terms
- Strong presence in Google AI Overviews, featured snippets, People Also Ask, and LLM citations (ChatGPT, Perplexity, Gemini, etc.)
- Excellent Core Web Vitals and mobile experience on South African connections
- Clear conversion paths that turn visitors into leads (forms, WhatsApp, phone, calendar booking)
- High trust signals and E-E-A-T

### Tech Stack Requirements (strict)
- Framework: Astro (preferred for maximum performance, zero JS by default, and SEO) or Next.js App Router with static generation if interactivity demands it. Prefer Astro unless strong justification exists.
- Styling: Tailwind CSS + a clean, modern design system
- Images: Optimized (WebP/AVIF), responsive, lazy-loaded, with proper width/height and alt text
- Forms: Secure, fast, spam-protected (Cloudflare Turnstile or equivalent), with clear success states and optional WhatsApp fallback
- Hosting-ready: Static or hybrid output suitable for Vercel, Cloudflare Pages, or Netlify
- Analytics: Ready for Google Search Console, GA4 or Plausible, and Bing Webmaster Tools
- Accessibility: WCAG 2.2 AA minimum
- Performance target: LCP < 2.0s, INP < 150ms, CLS < 0.05 on mobile

### Design & UX Requirements
- Modern, clean, professional, trustworthy aesthetic suitable for B2B South African clients
- Strong visual hierarchy and conversion-focused layout
- Mobile-first, fully responsive
- Clear primary CTA on every page (e.g. “Get a Free Quote”, “Book Discovery Call”, “WhatsApp Us”)
- Trust signals: process steps, results metrics, testimonials placeholders, client logos section, guarantees or differentiators
- Fast perceived performance, generous whitespace balanced with dense useful information
- Dark/light mode optional but not required, insure that it is optimized for all screens and broswers especially mobile and laptop screens
- Consistent design system (colors, typography, spacing, components)

### Content & SEO / AEO / GEO Requirements (critical)
- Write all page content in clear, authoritative, helpful English aimed at South African business owners
- Lead every major section with a direct answer or definition (AEO best practice)
- Use question-style H2/H3 headings that match real search queries
- Include comprehensive FAQ sections with schema on service pages and a dedicated FAQ page
- Make content self-contained and easy for LLMs to extract and cite (GEO)
- Strong entity clarity: repeatedly and naturally mention Conextsol, services, South Africa, key cities, and technologies
- Include original insights, process explanations, and result-oriented language
- Keyword focus examples (expand intelligently): web design South Africa, website developer Johannesburg, custom software development Cape Town, UI UX design South Africa, e-commerce website development, etc.
- Internal linking strategy that builds topical authority
- Meta titles, meta descriptions, Open Graph tags, and Twitter cards for every page
- Canonical tags and proper heading hierarchy

### Technical SEO & Structured Data
- Semantic HTML5 throughout
- Full JSON-LD schema on every relevant page: Organization, LocalBusiness, Service, FAQPage, BreadcrumbList, Article (for blog), WebSite, etc.
- XML sitemap generation
- robots.txt that allows major crawlers
- Breadcrumbs on all pages
- Fast, crawlable HTML (critical content not hidden behind JavaScript)
- Consider generating an /llms.txt file that summarizes the site and points to key pages for AI systems
