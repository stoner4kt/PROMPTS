# A website displaying perfumes and allows customers to place orders, sending those

A website displaying perfumes and allows customers to place orders, sending those orders to a spreadsheet sheet with the customers information. Perfume is till month end so the form should allow customers to choose a date range when they will be able to make the payment. 
I will host the site on netlify and use netlify functions to write to the spreadsheet and to notify the admin about orders, also a admin panel that allows admin to adjust stock levels and add stock in, perfume names, how much ml they are and a short description with the price. The system should also generate a pdf receipt invoice for the customer showing how much they order sums up the amount they owe

Use html, css, js only and make sure it optimized for all screens and devices especially mobile and laptops. Generate me this website in a repo folder with a setup Guide I can download and upload to my github
